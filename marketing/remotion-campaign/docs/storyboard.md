# TeaTimer App Promo Storyboard

Reference direction: vertical mobile app promo inspired by `https://www.youtube.com/shorts/XgM2_m2I6sE?feature=share`.

Use the reference for structure and motion only:

- Big iPhone mockup as the main visual.
- App UI clearly visible.
- Multiple phone frames moving smoothly.
- Screen changes inside the phone.
- Captions around the phone, never overpowering it.
- Tea lifestyle imagery as atmosphere only.

Do not copy the reference video's design, colors, text, or branding.
